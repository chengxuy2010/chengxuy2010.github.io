Raspberry Pi Nextcloud

Personal Google Drive integration for a self-hosted Nextcloud server.

About this application

This application connects Google Drive to a private, self-hosted Nextcloud installation running on a Raspberry Pi. It uses rclone and WebDAV to provide convenient access to the owner's Google Drive files through Nextcloud.

Purpose

The application allows its owner to browse and retrieve files from authorized Google Drive accounts through a personal Nextcloud server.

Google Drive access

The application requests read-only Google Drive permissions. Google Drive access is authorized individually by each account owner using Google OAuth.

Availability

This application is intended solely for personal use. It is not a commercial service and is not available for public registration.

Privacy
