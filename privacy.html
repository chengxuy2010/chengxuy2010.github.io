Privacy Policy

Application: Raspberry Pi Nextcloud

Effective date: November 12, 2026

1. Overview

Raspberry Pi Nextcloud is a private, personal-use application that connects authorized Google Drive accounts to a self-hosted Nextcloud server using rclone and WebDAV.

2. Google user data accessed

The application requests read-only Google Drive access. With the account owner's authorization, it may access Google Drive file contents, file names, folder structures, and associated metadata needed to display and retrieve files through Nextcloud.

3. Use of Google user data

Google user data is used solely to provide the account owner with access to their Google Drive files through their private Nextcloud installation. The application does not use Google user data for advertising, profiling, marketing, or unrelated purposes.

4. Data storage and security

OAuth credentials and authorization tokens are stored on the owner's private Raspberry Pi server in restricted configuration files. File contents and metadata may be temporarily cached on the server or stored by authorized Nextcloud clients to provide file access and improve performance.

Access to the server is restricted to authorized users. The application uses authenticated connections and appropriate access controls to protect Google user data.

5. Data sharing and disclosure

The application does not sell Google user data or disclose it to advertisers or data brokers. Google user data is processed by the owner's self-hosted rclone and Nextcloud installation and delivered to authorized devices for the requested file-access functionality.

Google user data is not published on this website. This website is hosted separately by GitHub Pages and contains only application information and this privacy policy.

6. Data retention and deletion

OAuth authorization tokens are retained while the Google Drive connection remains configured. Cached data may be retained temporarily according to the application's cache settings.

The account owner may remove the connection, delete locally stored credentials and cached data, and revoke the application's Google account authorization at any time. Locally downloaded files and any retained backup copies can be removed separately by the account owner.

7. Revoking access

Google account owners can review or revoke the application's access through their Google Account connections settings.

8. Google API Services User Data Policy

The application's use of information received from Google APIs will adhere to the Google API Services User Data Policy, including the Limited Use requirements.

9. Changes to this policy

This privacy policy may be updated if the application's functionality or data-handling practices change.

10. Contact

Questions about this application or its privacy practices may be directed to the application owner through the support email displayed on the Google OAuth consent screen.
